# Praveenkumar Pamisetty — Portfolio

**Live Website:** [https://portfolio-sooty-zeta-22.vercel.app](https://portfolio-sooty-zeta-22.vercel.app)

Interactive portfolio website for Praveenkumar Pamisetty, built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Three.js.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment

Hosted on Vercel: https://portfolio-sooty-zeta-22.vercel.app
